# 📊 Diretório de Dados

Este diretório é reservado para conjuntos de dados utilizados nos exercícios e projetos de IA:

- `raw/`: Dados originais e brutos (imutáveis).
- `processed/`: Dados transformados, limpos e prontos para treino de modelos.

> **Nota:** Arquivos de dados pesados (`.csv`, `.parquet`, `.h5`, `.pt`, etc.) estão configurados no `.gitignore` para não sobrecarregar o repositório Git. Armazene arquivos grandes localmente ou faça download diretamente nos scripts/notebooks quando necessário.
